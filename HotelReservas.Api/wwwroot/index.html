Cómo funciona

La consulta viaja a POST /api/asistente. El orquestador filtra datos personales, pide al modelo (Azure OpenAI GPT‑4o con llamada a funciones) la función a ejecutar, la valida contra el catálogo de solo lectura, la ejecuta sobre la base de datos y registra la consulta en CONSULTA_ASISTENTE. Sin credenciales de Azure, atiende el intérprete de reglas.
